# AyahOS Compute and Model Quality

AyahOS assigns compute responsibilities by role. The cognition path uses permitted Overmind providers or explicitly eligible compute nodes; independent Undermind authority remains separate. Node 001 is a cognitive worker, not an Undermind replacement. Embedding workloads belong to a distinct capability and should use bounded compute resources without displacing production chat inference. Site delivery and cognition routing are separate components. The platform preserves model quality constraints and must not quietly substitute a weaker chat model to conceal a provider outage.

_This public-safe summary is retrieval context, not policy authority. Undermind's deterministic checks remain authoritative._
