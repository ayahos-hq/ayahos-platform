# AyahOS Governance and Shared Spine

AyahOS separates cognitive work and independent control. Overmind generates candidate responses and uses retrieved documents as evidence. Undermind checks permissions, safety, budgets, capabilities, and execution constraints. Its deterministic decisions are authoritative: advisory model critics cannot override those decisions, grant permissions, or bypass restrictions. The Shared Spine records decisions and outcomes so the system can distinguish verified actions from suggestions. If no permitted provider or compute route is available, AyahOS reports the failure instead of inventing a completed inference.

_This public-safe summary is retrieval context, not policy authority. Undermind's deterministic checks remain authoritative._
